# 原版功能补齐进度

已接入八大世界32关、全部源奖励分区和跳关出口，支持单人及2–4人合作。

1. **关卡和敌人。**游泳、藤蔓与天空回程、天平和下落平台、弹簧、飞鱼、炮弹、锤子兄弟、Lakitu/刺龟、甲虫及水下敌人。
2. **城堡迷宫。**4-4、7-4 的高度路线迷宫与失败重走；8-4 的多区域管道迷宫、水下火棒和最终城堡。
3. **旗杆过场。**滑落、翻身下杆、自动进城、逐时转分、尾数1/3/6烟花、城堡升旗。
4. **救援过场。**逐段断桥、酷霸王坠落、自动走向 NPC、分行对话；世界1–7继续下一世界，世界8救援公主并显示结局，B返回选世界。
5. **大厅和合作。**快速加入、私密邀请、每人生命、共享关卡、重连和房主转移。

验证来源、10个代表关卡回放与边界见 [CAMPAIGN_AUDIT.md](CAMPAIGN_AUDIT.md)。当前仍是网页合作移植。
