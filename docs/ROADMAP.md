# 原版功能补齐顺序

当前已保留上游单人模式的移动、跳跃、蹲下、顶砖块、栗宝宝、蘑菇、火焰花、地上/地下随机地形和旗杆。

联机模式已增加2–4人房间、全员准备、统一关卡与敌人/砖块/道具状态、团队计分、每人3条命、检查点复活、100金币全员加命、走跑与长短跳、45秒重连和房主转移。

1. **原版固定关卡与连续闯关。**先制作可核对的1-1、1-2关卡数据，再扩展第一世界。当前单人是随机关卡，联机是合作草地，不能标作原版32关。
2. **乌龟与龟壳。**上游目前只有相关图片/动画，缺少实际AI、踩龟缩壳、踢壳和连续击杀；应在服务端统一计算，并补跨客户端验证。
3. **隐藏奖励与水管。**补下蹲入管的奖励房、隐藏砖、绿蘑菇、藤蔓与跳关区；上游已有部分水管传送，应复用而非重复实现。
4. **城堡与酷霸王。**补火杆、火球、斧头断桥、Boss和救人过场，统一团队过关及下一关流程。
5. **原版规则与手感对照。**核对各形态受伤规则、旗杆分档、余时转分、连踩加分、跑跳惯性和音效时序。在线预测与网络抖动补偿也应纳入手感验收。

参考：任天堂托管的《Super Mario Bros.》原版手册：
