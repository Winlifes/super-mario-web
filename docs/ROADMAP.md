# 原版功能补齐进度

本版已上线：

1. **第一世界固定关卡。**1-1、1-2、1-3、1-4及其子区域，触旗换关，保存形态、剩余生命、金币和团队分数；支持从任一关开始练习。
2. **乌龟与龟壳。**绿/红龟、飞龟、去翼、踩龟缩壳、踢壳、反弹、壳复苏与连续击杀。联机由服务端计算。
3. **奖励房和道具。**1-1/1-2原位置水管及金币房出口、隐藏绿蘑菇、星星和多金币砖；支持手机“↓”入管。
4. **第一世界城堡。**火棒、岩浆、酷霸王跳跃和吐火、五火球击败、斧头断桥、奇诺比奥终点。
5. **大厅。**公开房间列表、人数/关卡/状态、快速加入、私密邀请房、单人挑战；保留45秒重连和房主转移。

验证包含服务端规则、真实WebSocket客户端同步、浏览器键盘与手机尺寸检查，以及四关从正常出生点以按键完成的回放。测试范围和来源见 `SOURCE_AUDIT.md`。

接下来按顺序继续：

1. 世界2–8及对应游泳、藤蔓天空区和跳关出口；当前1-2跳关房明确标记后续世界未开放。
2. 旗杆滑落/进城、烟花、断桥分段坠落等完整过场与最终公主救援。
3. 与NES运行证据逐帧核对跑跳、敌人计时、无敌/形态动画和原版时间单位；当前仍是60Hz网页物理移植。
4. 网络条件模拟、本地输入预测与远端插值优化。
